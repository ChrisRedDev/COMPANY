# Local Plumbing Services DEMO files

Every contact, transaction, performance value, rank and review metric is synthetic. No call-tracking number has been provisioned and no external messages are sent. The JSON pack is loaded by the DEMO button into a separate SQLite workspace; its dates are shifted relative to the day of first loading. Loading again opens the same demo. The CSV files demonstrate validated import schemas and use the reference date 6 October 2026. Real imports must use GBP and Europe/London. Ads conversions are platform-reported; CRM outcomes and revenue come from lead events. Calls use stable provider IDs for replay protection. Search-term rows show keyword-level CRM outcomes, not fabricated exact search-term attribution.

The Company Brain is owner-supplied public research, not demo account performance.
